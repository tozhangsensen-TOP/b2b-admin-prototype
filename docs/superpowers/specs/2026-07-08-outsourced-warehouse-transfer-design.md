# 外租库转运本库功能设计

## 业务背景
- 本库容量有限，部分库存存放在外租库
- 当本库库存不足时，需要从外租库转拨到本库满足发运需求
- 系统定时生成转拨建议，人工确认后执行

## 二、数据结构设计

### 转拨建议表
```typescript
interface TransferSuggestion {
  id: string;           // 建议ID
  createTime: Date;    // 生成时间
  status: 'pending' | 'confirmed' | 'cancelled'; // 状态
  createType: 'auto' | 'manual'; // 生成方式
  items: TransferSuggestionItem[]; // 商品清单
}

interface TransferSuggestionItem {
  skuCode: string;    // 商品编码
  skuName: string;    // 商品名称
  mainStock: number;  // 本库库存
  outsourcedStock: number; // 外库库存
  demandQty: number;  // 待发运量
  suggestQty: number; // 建议数量
  actualQty: number;  // 实际数量
}
```

## 三、核心逻辑设计

### 3.1 定时任务逻辑

**执行时机**：每天08:00自动执行

**计算规则**：
1. 统计未来N天（默认：3天）的待发运订单，按商品汇总需求
2. 对比本库现有库存
3. 计算缺口：`需求 - 本库库存
4. 如果缺口>0，则建议从外库转入
5. 优先满足发运需求
6. 剩余外库库存，按目标库存补充

**建议数量公式**：
```
建议数量 =  MAX(0, 发运需求 - 本库库存) + 补库量（若外库还有库存）
```


### 3.2 页面交互逻辑

**编辑时校验**：
- 实际数量不能超过外库库存
- 实际数量不能小于0
- 至少保留至少有一个商品才能提交

**提交逻辑**：
- 提交后，建议状态变为"已确认"
- 调用WMS接口创建转拨单
- 记录提交人、提交时间
